# 💗 Connect — Социальная сеть

**Connect** — современная социальная сеть, созданная для общения, обмена впечатлениями и связи между людьми. Проект сочетает в себе простой интерфейс, современный дизайн и удобные возможности для пользователей.

🌐 **Сайт:** [Connect](connect.pntr.dev)

---

## ✨ Возможности

- 👤 Регистрация и авторизация пользователей
- 🔐 Безопасная система входа
- 💬 Общение и социальные функции
- 📱 Адаптивный дизайн для мобильных устройств
- 🎨 Современный и минималистичный интерфейс
- ⚡ Быстрая работа сайта
- ☁️ Использование Supabase для backend-инфраструктуры

---

## 🛠️ Технологии

| Технология | Назначение |
|---|---|
| HTML5 | Структура сайта |

## 📱 Connect

Connect создаётся с целью сделать онлайн-общение простым, удобным и доступным.

Проект постоянно развивается, а новые функции и улучшения появляются в обновлениях.

## 🚀 Запуск проекта

1. Открой репозиторий проекта.
2. Склонируй репозиторий:

   ```bash
   git clone https://github.com/setkarosetka-hue/connect-social.git
   ```

3. Открой папку проекта.
4. Запусти `index.html` или используй GitHub Pages.
